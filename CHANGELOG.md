# Changelog

Each release's notes come from its section here; the release workflow fails
without one. Write for users: what changed, and anything to do by hand.

## 0.1.0

First release as a Codex plugin installed from this repository's marketplace.

- Install with `codex plugin marketplace add shemarlindie/codex-subagent-extension@release`, then `codex plugin add codex-subagent-extension@shemarlindie`.
- If you configured the extension by hand before, remove `[mcp_servers.codex_subagent_extension]` from `~/.codex/config.toml` so Codex doesn't run two copies.
